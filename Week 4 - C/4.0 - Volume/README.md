## 🧠 What is this about?
This project involves writing a C program, `volume.c`, that modifies the volume of a WAV audio file. The program reads the input WAV file, scales each audio sample by a given factor to adjust the volume, and writes the modified samples to an output WAV file. This task requires understanding of file I/O operations and handling of binary data in C.
