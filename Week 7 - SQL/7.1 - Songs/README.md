# 📝 Week 7.1 - Songs

## 🔗 Resources
- **Problem Statement:** [Songs Problem Set](https://cs50.harvard.edu/x/psets/7/songs/)

## 🧠 What is this about?
This project involves writing a series of SQL queries to analyze data from Spotify’s 100 most-streamed songs of 2018. Using a provided SQLite database (songs.db), the queries extract information about songs and artists, including attributes such as danceability, energy, valence, and tempo. Tasks include listing songs, ordering by specific criteria, computing averages, and filtering results based on artist names or song characteristics. The project emphasizes SQL fundamentals such as SELECT, WHERE, ORDER BY, and aggregation functions.
