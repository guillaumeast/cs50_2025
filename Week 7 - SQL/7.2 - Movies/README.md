# 📝 Week 7.2 - Movies

## 🔗 Resources
- **Problem Statement:** [Movies Problem Set](https://cs50.harvard.edu/x/psets/7/movies/)

## 🧠 What is this about?
This project involves querying a SQLite database (movies.db) containing information from IMDb about movies, people, and ratings. A series of SQL problems require extracting, joining, and aggregating data to answer questions about movie releases, actors, directors, and ratings. Key tasks include selecting movies by year, identifying cast members, computing averages, and correlating people and films through joins. The project reinforces proficiency with relational databases, filters, sorting, and subqueries in SQL.
