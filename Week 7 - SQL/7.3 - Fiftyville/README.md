# 📝 Week 7.3 - Fiftyville

## 🔗 Resources
- **Problem Statement:** [Fiftyville Problem Set](https://cs50.harvard.edu/x/psets/7/fiftyville/)

## 🧠 What is this about?
This project involves investigating a mystery using SQL queries on a relational database (fiftyville.db). The goal is to identify the thief, their destination, and their accomplice by analyzing data from the town of Fiftyville. Students log each query and reasoning step in log.sql, documenting the process of narrowing down suspects through records of transactions, phone calls, flights, and interviews. The project focuses on critical thinking, data analysis, and applying SQL joins and conditions to piece together evidence from multiple tables.
