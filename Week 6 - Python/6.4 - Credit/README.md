## 🧠 What is this about?
This project involves implementing a credit card validator in Python. The program prompts the user for a credit card number, determines whether it is valid using Luhn’s algorithm, and identifies the type of card (American Express, MasterCard, or Visa) based on its number pattern. It emphasizes numeric operations, control flow, and string manipulation to classify and validate card numbers.
