## 🔗 Resources

## 🧠 What is this about?
This project involves writing a Python program that calculates the readability grade level of a given text using the Coleman-Liau index. The program prompts the user for text input, counts letters, words, and sentences, and computes the index using the formula 0.0588 * L - 0.296 * S - 15.8. It then outputs the corresponding grade level, rounded to the nearest integer. The exercise highlights text analysis, arithmetic computation, and conditional output formatting in Python.
