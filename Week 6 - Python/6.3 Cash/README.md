# 📝 Week 6.3 - Cash

## 🔗 Resources
- **Problem Statement:** [Cash Problem Set](https://cs50.harvard.edu/x/psets/6/cash/)

## 🧠 What is this about?
This project involves writing a Python program that determines the minimum number of coins needed to make a given amount of change. The program prompts the user for the amount owed in dollars, validates that the input is non-negative, and computes the fewest number of U.S. coins (quarters, dimes, nickels, and pennies) required to make that change. It focuses on loops, conditional logic, and handling floating-point input accurately.
