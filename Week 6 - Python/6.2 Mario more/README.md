# 📝 Week 6.2 - Mario More

## 🔗 Resources
- **Problem Statement:** [Mario More Problem Set](https://cs50.harvard.edu/x/psets/6/mario/more/)

## 🧠 What is this about?
This project involves generating a double half-pyramid in Python, similar to the pyramids from the Mario game. The program prompts the user for a height between 1 and 8 inclusive, validates the input, and prints two adjacent half-pyramids separated by two spaces. It focuses on nested loops, precise alignment, and string manipulation to reproduce the correct pyramid shape.
