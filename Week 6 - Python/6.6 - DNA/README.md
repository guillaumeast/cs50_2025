## 🧠 What is this about?
This project involves implementing a DNA profiling program in Python. The program analyzes a DNA sequence and compares it against a database of individuals represented in a CSV file containing Short Tandem Repeat (STR) counts. It computes the longest consecutive runs of each STR within the sequence and identifies which individual’s STR profile matches exactly. The project focuses on file handling, string pattern analysis, and data comparison using loops and dictionaries.
